# Parshwa Consultancy Public Website

Public website application for Parshwa Consultancy built with React.js, Vite, React Router, and modular CSS.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Structure
- `src/components/` - Reusable UI components & section modules
- `src/pages/` - Top-level page views (Home, About, Services, Investment Solutions, Resources, Contact)
- `src/routes/` - Central application routes (`AppRoutes.jsx`)
- `src/styles/` - Modular CSS architecture (variables, globals, typography, responsive, animations)
- `src/services/` - API integrations (Node.js backend & CMS workflow interfaces)
- `src/utils/` - Global constants and helper functions
